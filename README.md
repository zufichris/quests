# Seventy-Five Days

A single `index.html`. One quest set a day for 75 days. State lives in your browser's localStorage only. Nothing is tracked.

## Host on GitHub Pages

1. Create a repository and push this folder.
2. Settings → Pages → Source: `main`, folder `/ (root)`.
3. Open the Pages URL. Press Begin.

## Preview any day

Append `?day=N` to the URL, for example `?day=37`. Preview mode does not write to storage.
