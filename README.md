# Seventy-Five Days

A single `index.html`. One quest set a day for 75 days: a theory quest, a bench quest, the daily log, and a sketchbook page. Quests name topics to understand and things to build, not platforms. Where you learn each topic is your choice.

State lives in your browser's localStorage only. Nothing is tracked.

Live: https://zufichris.github.io/quests/

## Preview any day

Append `?day=N` to the URL, for example `?day=37`. Add `&done=1` to see the completed state, `&theme=dark` to force a theme, or `&all=1` for the whole sprint. Preview mode never writes to storage.
